# Учёт мясного производства

Прототип финансового и товарного учёта мясного производства. Только фронтенд: введённые числа сохраняются в браузере, формулы считаются на клиенте, мок-данные можно вернуть одной кнопкой.

Сейчас в правилах и в [docs/domain.md](docs/domain.md) зафиксирован первый срез: доходы и себестоимость продукции. В блоке «Продажи» пункты: Отчет общий, Отчет подневный, Ввод плана, Ввод продаж. Товары заводят во «Вводе плана». Плановые операционные расходы одной суммой без НДС правят во «Вводе плана», фактические — в «Отчете общем». Одна кнопка «Вернуть мок-данные» внизу бокового меню сбрасывает весь документ.

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).
