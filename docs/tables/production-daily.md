# Отчет подневный производства

`/production/fact`. Дневная сетка выпуска. Месяц, один день или все даты. Сравнения с планом нет, ввода нет. Заголовок страницы: «Выпуск на …» в режиме дня, «Выпуск за …» по всем датам.

Считает `src/domain/production-journal-fact.ts`. Рекомендация дня — `src/domain/movement-plan.ts`.

## Колонки строки товара

| Колонка | Формула |
| --- | --- |
| Объём | Сумма штук [записей выпуска](production-entry.md) за этот день |
| Рекомендуемый объём | [Рекомендация](../flow.md#recommended) по остатку на конец этого дня. Норматив — месяца. В последний день совпадает с месяцем во [вводе плана движения](movement-plan.md) и с колонкой плана в [отчёте общем](production-summary.md) |
| Цена | Сумма строк журнала этого дня / штуки. Нет выпуска — 0 |
| Стоимость | Сумма сумм строк журнала за день. Нет выпуска — 0 |

Начало дня — как в [подневном движении](movement-daily.md): 1-е число — инвентаризация месяца, дальше конец предыдущего дня. Конец дня = начало дня + выпуск дня − продажи дня.

Категория и «Всего»: сумма объёмов, сумма стоимостей, сумма рекомендаций. Цена = итог / объём; выпуска нет — 0.

Штуки и стоимость месяца в [отчёте общем](production-summary.md) равны сумме дней. Рекомендуемый объём месяца — не сумма дней: это одна цифра на конец месяца.
