# Отчет общий движения

`/movement`. Свод готовой продукции за месяц или интервал «с — по». Будущие месяцы не выбираются, по умолчанию открыт текущий. Ввода нет.

Один месяц считается как интервал из этого месяца. Правила начала, суммы и конца — в [остатке](../flow.md#stock).

В текущем месяце продажи и выпуск — уже введённые записи за все даты месяца, в том числе после сегодня.

Считает `src/domain/finished-goods.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| План | Конец прошлого месяца. Смотрят здесь, считают в [инвентаризации](inventory.md) |
| Факт | Инвентаризация первого месяца интервала. Ввод — в [инвентаризации](inventory.md) |
| Откл. | Факт − план |
| Цена | Продажи месяца перед «с»: выручка / штуки. Штук не было — плановая цена того месяца, как во [вводе плана продаж](sales-plan.md). Нет прошлого месяца — пусто |
| Стоимость отклонения | Отклонение × эта цена |
| Стоимость | Факт × эта цена |

## Продажи

| Колонка | Формула |
| --- | --- |
| Объём | Штуки [журнала продаж](sale-form.md) за интервал. Совпадает с фактом [отчёта общего продаж](sales-summary.md) без линзы |
| Цена | Выручка / штуки. На строке товара это та же цена, что «Цена (факт)» у конца |
| Стоимость | Выручка журнала за интервал |

## Производство

| Колонка | Формула |
| --- | --- |
| Объём | Штуки [журнала выпуска](production-entry.md) за интервал |
| Цена | Стоимость / штуки. Стоимость = цена × объём, как у продаж. Выпуска не было — 0 |
| Стоимость | Сумма строк журнала (цена × штуки). Выпуска не было — 0 |

## Остаток на конец

| Колонка | Формула |
| --- | --- |
| Остаток | Начало (факт) последнего месяца + его выпуск − его продажи |
| Мин, Макс | Норматив последнего месяца из [ввода плана](movement-plan.md) |
| Откл. | [Отклонение от норматива](../flow.md#recommended) этого остатка |
| Цена (факт) | Выручка / штуки продаж всего интервала. Нулевой объём — 0 |
| Стоимость | Остаток на конец × цена факта. Нет цены — пусто |

Категория и «Всего»: штуки и деньги суммируются, мин и макс — сумма строк. Цена начала = стоимость начального остатка / штуки факта. Цена продаж и цена факта = выручка / штуки. Цена производства = сумма стоимостей / сумма штук. «Откл.» — [правило итога](../flow.md#recommended).

Те же колонки по дням, кроме плана и отклонения начала, — в [подневном отчёте](movement-daily.md). Стоимость остатка на своде идёт от цены месяца или интервала, поэтому она не равна сумме стоимостей дней.
