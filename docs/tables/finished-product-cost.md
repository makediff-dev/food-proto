# Себестоимость готовой продукции

`/recipes/finished/cost`. Месяц. Строки — рабочие товары по заводам. Ввода нет. Строка раскрывает состав в той же таблице.

Считает `src/domain/finished-product-cost.ts`. Книга: `Rec&Calc Final Products`, себестоимость 1 шт (план ~D192, факт ~D326). Плановая потребность в эти формулы не входит.

## Свод

| Колонка | Формула |
| --- | --- |
| План · ₽/шт | Стоимость партии по плановым ценам / штуки партии |
| Факт · ₽/шт | Стоимость партии по фактическим ценам расхода / штуки партии |
| Откл. · ₽/шт | Факт − план |
| План · ₽/кг | Если задан выход кг: стоимость партии / кг |
| Факт · ₽/кг | То же по фактическим ценам |
| Откл. · ₽/кг | Факт − план; нет кг — пусто |

Стоимость партии = сумма по строкам рецепта с количеством > 0: количество × цена единицы компонента. Материал — `materialPlanPrice` / `materialConsumptionPrice`. Производная — `derivativeConsumptionPrice`.

Эту ₽/шт берут план и факт продаж того же месяца. План — плановую, факт — фактическую. В Т-проток идёт сумма без НДС.

## Состав строки

Прямые ингредиенты рецепта под раскрытой строкой: имя, количество, цена план/факт, вклад план/факт, отклонение вклада. Нулевые количества и отсутствующие компоненты скрыты. Внизу вложенной таблицы одна строка «Всего»: сумма количества (если одна единица), себестоимость за кг в «Цена план/факт» (нет выхода кг — за шт), сумма вклада в рублях; при заданном выходе кг ниже ещё «За шт».
