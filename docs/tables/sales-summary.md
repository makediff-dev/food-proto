# Отчет общий продаж

`/`. План и факт продаж за месяц или интервал «с — по». Ассортимент и план здесь не правят. Факт приходит из [ввода продаж](sale-form.md) через [подневный отчёт](sales-daily.md).

Режимы — [прогноз и фактическая](../flow.md#lens). В прогнозе открытого периода группа факта подписана «(прогноз)», план — «Плановые показатели». В фактической план подписан «(корр.)»: это урезанный план. Когда конец периода уже прошёл, пометки «(прогноз)» нет.

Считает `src/domain/summary.ts`.

<a id="headline"></a>

## Верхний блок

Колонки: план, факт, отклонение (факт − план). В клетке одно число.

| Строка | План и факт |
| --- | --- |
| Выручка с НДС | Сумма выручки с НДС по товарам |
| Т-проток | Сумма [Т-протока](../flow.md#contribution) по товарам |
| Операционные расходы | [Сумма без НДС](../flow.md#opex). План вводят во [вводе плана](sales-plan.md). Факт — здесь, при одном месяце |
| Прибыль | Т-проток − операционные расходы |
| Налог на прибыль | Прибыль × 20 % |
| Чистая прибыль | Прибыль − налог |
| Рентабельность | [Чистая прибыль / выручка без НДС](../flow.md#profitability) |

Отклонение каждой строки — факт − план, в том числе у рентабельности.

## Сетка

Три группы: плановые показатели, фактические показатели, отклонение.

Плановые колонки — те же, что во [вводе плана](sales-plan.md): себест, рентаб, цена, объём продаж, выручка, Т-проток, себест объёма, в сутки, НДС. В фактической это уже урезанный план. «В сутки» у такого плана — урезанный объём / прошедшие дни.

Фактические колонки — тот же набор. Цифры — из журнала продаж, себестоимость штуки — с товара, как в [подневном отчёте](sales-daily.md). За один месяц до линзы это сумма дней. Линза прогноза одного открытого месяца растягивает объём, выручку, себестоимость объёма и Т-проток одной долей, затем заново делит цену и «в сутки» на дни месяца. Рентабельность строки плана от объёма не зависит и при урезке не меняется.

За интервал штуки и деньги складываются, цена берётся из сумм. «В сутки» плана в фактической — штуки плана / прошедшие дни периода, факта — штуки факта / календарные дни периода.

Отклонение — две колонки: выручка с НДС и Т-проток. Обе: факт − план.

Категория и «Всего» — [итог группы](../flow.md#group).
