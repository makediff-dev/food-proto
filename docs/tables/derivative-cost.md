# Себестоимость производных

Пункт меню «Себестоимость производных». `/recipes/cost`. Месяц. Строки — рабочие производные по цехам. Ввода нет. Строка раскрывает состав в той же таблице.

Считает `src/domain/derivative-cost.ts`. Книга: блоки «себестоимость 1 кг» на `Rec&Calc Meat` / `Bakery` / `Vegetables` (план и факт). Плановая потребность в эти формулы не входит.

## Свод

| Колонка | Формула |
| --- | --- |
| План · ₽/кг | Стоимость партии по плановым ценам сырья / выход кг |
| Факт · ₽/кг | Стоимость партии по фактическим ценам расхода сырья / выход кг |
| Откл. · ₽/кг | Факт − план |
| План · ₽/шт | Только при единице «шт»: стоимость партии / штуки партии |
| Факт · ₽/шт | То же по фактическим ценам |
| Откл. · ₽/шт | Факт − план; нет штук — пусто |

Стоимость партии = сумма по строкам рецепта с количеством > 0: количество × цена единицы компонента. Материал — `materialPlanPrice` / `materialConsumptionPrice`. Вложенная производная — рекурсивно цена её учётной единицы. Цикл → 0.

Себест. единицы производной на [своде движения](derivative-movement-summary.md) — та же арифметика (`derivativeConsumptionPrice`).

## Состав строки

Деньги на своде и в составе — только без НДС, одноэтажная клетка с подписью «без НДС».

Прямые ингредиенты рецепта под раскрытой строкой: имя, количество, цена план/факт, вклад план/факт, отклонение вклада. Нулевые количества и отсутствующие компоненты скрыты. Внизу вложенной таблицы одна строка «Всего»: сумма количества (если одна единица), себестоимость за кг в «Цена план/факт», сумма вклада в рублях; при поштучной производной ниже ещё «За шт».
