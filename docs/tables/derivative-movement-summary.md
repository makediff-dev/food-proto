# Отчет общий движения производных

`/derivative-movement`. Месяц. Строки — рабочие производные по цехам. Ввода нет.

Считает `src/domain/derivative-movement.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| Факт | Инвентаризация конца прошлого месяца. Нет прошлого месяца или записи — 0 |

## Приход

Девять колонок: план (количество, себест., стоимость), факт (количество, себест., стоимость), отклонение (количество, себест., стоимость). Отдельного журнала выпуска производных нет: количество плана и факта — рекомендуемый объём из [ввода плана](derivative-movement-plan.md).

| Колонка | Формула |
| --- | --- |
| План · Кол-во | Рекомендуемый объём выпуска |
| План · Себест. | Себестоимость единицы по плановым ценам сырья |
| План · Стоимость | Себест. × количество |
| Факт · Кол-во | Пока журнала нет — тот же рекомендуемый объём |
| Факт · Себест. | Себестоимость единицы по фактическим ценам расхода сырья |
| Факт · Стоимость | Себест. × количество |
| Отклонение · Кол-во | Факт − план (количество) |
| Отклонение · Себест. | Факт − план (себест.) |
| Отклонение · Стоимость | Факт − план (стоимость) |

## Расход в производство

Пятнадцать колонок: план, расчётный, реальный, откл. к расчёту, откл. к плану (у каждой — количество, себест., стоимость).

| Колонка | Формула |
| --- | --- |
| План · Кол-во | Расход на выпуск по рецептам из плана выпуска |
| План · Себест. | Себестоимость единицы по плановым ценам сырья |
| План · Стоимость | Себест. × количество |
| Расчётный · Кол-во | Расход на выпуск по рецептам из журнала |
| Расчётный · Себест. | Себестоимость единицы по фактическим ценам расхода сырья |
| Расчётный · Стоимость | Себест. × количество |
| Реальный · Кол-во | Сумма дневного ввода «Расход в производстве» |
| Реальный · Себест. | Та же фактическая себестоимость единицы |
| Реальный · Стоимость | Себест. × реальное количество |
| Откл. к расчёту · Кол-во | Реальный − расчётный |
| Откл. к расчёту · Себест. | 0 |
| Откл. к расчёту · Стоимость | Реальная стоимость − расчётная |
| Откл. к плану · Кол-во | Реальный − план |
| Откл. к плану · Себест. | Фактическая − плановая |
| Откл. к плану · Стоимость | Реальная стоимость − плановая |

## Остаток на конец

Одиннадцать колонок, как в отчёте сырья.

| Колонка | Формула |
| --- | --- |
| План | Начало + план прихода − план расхода |
| Расчётный · Факт | Начало + факт прихода − реальный расход |
| Расчётный · Откл. | Расчётный факт − план |
| Расчётный · Стоим. откл. | Отклонение × фактическая себестоимость расхода |
| Инвентаризация · Факт | Ввод в [инвентаризации](derivative-movement-inventory.md). Пока не правили — 0 |
| Инвентаризация · Откл. | Факт инвентаризации − план. Нет строки инвентаризации — 0 |
| Инвентаризация · Стоим. откл. | Отклонение × фактическая себестоимость расхода. Нет строки — 0 |
| Нормативный · Мин., Макс. | Норматив месяца из [ввода плана](derivative-movement-plan.md). Пока не правили — 0 |
| Нормативный · Откл. | Запас на конец (факт инвентаризации, если вводили, иначе план) относительно мин/макс |
| Стоимость | (Инвентаризация или план) × фактическая себестоимость расхода |

Итог цеха суммирует стоимости прихода и расхода (план, факт и отклонение), стоимости отклонений конца и стоимость остатка; количества по разным единицам не складывают.
