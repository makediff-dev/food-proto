# Отчет общий движения производных

`/derivative-movement`. Месяц. Строки — рабочие производные по цехам. Ввода нет.

Считает `src/domain/derivative-movement.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| Факт | Инвентаризация конца прошлого месяца. Нет прошлого месяца или записи — 0 |

## Расход в производство

Девять колонок: план (количество, цена, стоимость), факт (количество, цена, стоимость), отклонение (количество, цена, стоимость).

| Колонка | Формула |
| --- | --- |
| План · Кол-во | Расход на выпуск по рецептам из плана выпуска |
| План · Цена | Себестоимость единицы по плановым ценам сырья |
| План · Стоимость | Цена × количество |
| Факт · Кол-во | Расход на выпуск по рецептам из журнала |
| Факт · Цена | Себестоимость единицы по фактическим ценам расхода сырья |
| Факт · Стоимость | Цена × количество |
| Отклонение · Кол-во | Факт − план (количество) |
| Отклонение · Цена | Факт − план (цена) |
| Отклонение · Стоимость | Факт − план (стоимость) |

## Остаток на конец

Одиннадцать колонок, как в отчёте сырья. Отдельного журнала выпуска производных нет: роль «прихода» в плане и расчётном факте играет рекомендуемый объём из [ввода плана](derivative-movement-plan.md).

| Колонка | Формула |
| --- | --- |
| План | Начало + рекомендуемый объём − план расхода |
| Расчётный · Факт | Начало + рекомендуемый объём − факт расхода |
| Расчётный · Откл. | Расчётный факт − план |
| Расчётный · Стоим. откл. | Отклонение × фактическая цена расхода |
| Инвентаризация · Факт | Ввод в [инвентаризации](derivative-movement-inventory.md). Пока не правили — 0 |
| Инвентаризация · Откл. | Факт инвентаризации − план. Нет строки инвентаризации — 0 |
| Инвентаризация · Стоим. откл. | Отклонение × фактическая цена расхода. Нет строки — 0 |
| Нормативный · Мин., Макс. | Норматив месяца из [ввода плана](derivative-movement-plan.md). Пока не правили — 0 |
| Нормативный · Откл. | Запас на конец (факт инвентаризации, если вводили, иначе план) относительно мин/макс |
| Стоимость | (Инвентаризация или план) × фактическая цена расхода |

Итог цеха суммирует стоимости расхода (план, факт и отклонение), стоимости отклонений конца и стоимость остатка; количества по разным единицам не складывают.
