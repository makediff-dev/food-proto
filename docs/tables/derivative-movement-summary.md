# Отчет общий движения производных

`/derivative-movement`. Месяц. Строки — рабочие производные по цехам. Ввода нет.

Считает `src/domain/derivative-movement.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| Факт | Инвентаризация конца прошлого месяца. Нет прошлого месяца или записи — 0 |

## План расхода / Факт расхода

| Колонка | Формула |
| --- | --- |
| Кол-во | Расход на выпуск готовой продукции по рецептам: план — из плана выпуска, факт — из журнала |
| Цена | Себестоимость 1 единицы производной из цен компонентов рецепта |
| Стоимость | Цена × количество |

## Остаток на конец

| Колонка | Формула |
| --- | --- |
| Инвентаризация · Факт | Ввод в [инвентаризации](derivative-movement-inventory.md). Пока не правили — 0 |
| Нормативный · Мин., Макс. | Норматив месяца из [ввода плана](derivative-movement-plan.md). Пока не правили — 0 |
| Нормативный · Откл. | Отклонение факта инвентаризации на конец от мин/макс |

Выпуск производных отдельно не фиксируется, поэтому расчётного и планового остатка на конец нет. Итог цеха суммирует стоимости расхода; количества по разным единицам не складывают.
