# Отчет подневный продаж

`/sales`. Дневная сетка факта. Месяц, один день или все даты. Сравнения с планом нет, ввода нет. Заголовок страницы: «Продажи на …» в режиме дня, «Продажи за …» по всем датам. Штуки и цены здесь не вводят: они приходят из [продаж](sale-form.md).

Считает `src/domain/sales-fact.ts`.

## Колонки строки товара

| Колонка | Формула |
| --- | --- |
| Себест продажи | [Себестоимость 1 шт](../flow.md#unit-cost) товара. Это не себестоимость выпуска |
| Рентаб | [Т-проток / себестоимость объёма без НДС](../flow.md#profitability) |
| Цена | Выручка дня / штуки дня. См. [цену](../flow.md#price) |
| Объём продаж | Сумма штук продаж этого дня и товара |
| Выручка | Сумма сумм строк продаж. Без НДС — сумма уже округлённых сумм строк |
| Т-проток | [Т-проток](../flow.md#contribution) дня |
| Себест объёма | Себестоимость штуки товара × штуки продаж. См. [себестоимость объёма](../flow.md#volume-cost) |
| НДС | Ставка товара |

Факт [отчёта общего](sales-summary.md) за один месяц до [линзы](../flow.md#lens) — сумма этих дней. Там те же показатели и ещё колонка «В сутки».

Категория и «Всего»: штуки, обе выручки, Т-проток и обе себестоимости объёма суммируются. Цена с НДС = выручка с НДС / штуки, цена без НДС = выручка без НДС / штуки. Себестоимость штуки = себестоимость объёма / штуки. НДС и рентабельность — [из итога](../flow.md#group).

Стоимость остатка в [движении](movement-summary.md) считается от цены месяца, поэтому с суммой дневных стоимостей она может не совпасть.
