# Ввод плана движения производных

`/derivative-movement/plan`. Месяц. Здесь вводят норматив мин/макс по производным. Над столбцами группа «Плановые показатели».

Считает `src/domain/derivative-movement.ts`.

## Колонки

| Колонка | Откуда |
| --- | --- |
| Мин., Макс. | Ввод, тысячные доли единицы производной (`кг` или `шт`), в том числе отрицательные. Пока не правили — 0 |
| Откл. | Отклонение факта инвентаризации на конец от мин/макс |
| Реком. объём | `план расхода + (мин + макс) / 2 − остаток на начало` (не меньше 0) |

## Что пишется

Норматив месяца (`derivativeNorms`): минимум и максимум по производной. Отклонение и рекомендуемый объём в документ не пишутся. Первая правка создаёт запись месяца.
