# Инвентаризация производных

`/derivative-movement/inventory`. Месяц. Здесь вводят остаток на конец (факт).

Считает `src/domain/derivative-movement.ts`.

## Колонки

Надзаголовок группы — «Остаток на конец», столбец — «Факт».

| Колонка | Откуда |
| --- | --- |
| Факт | Ввод, тысячные доли единицы, в том числе отрицательные. Пока не правили — 0 |

Выпуск производных отдельно не ведётся, поэтому столбцов «План» и «Откл.» нет. Факт конца месяца переносится на начало следующего.

## Что пишется

Инвентаризация месяца: количество по производной на конец месяца (`derivativeOpenings`). Первая правка создаёт запись месяца.
