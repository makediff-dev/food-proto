# Отчет общий сырья

`/materials`. Четыре группы. В каждой две таблицы: склад 1 (производство 1) и склад 2 (производство 2). Общего итога двух складов нет.

Считает `src/domain/materials.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| Остаток | Инвентаризация конца прошлого месяца этого склада. Январь 2000 или нет записи — 0 |

## Приход от поставщика

Девять колонок: план (количество, цена, стоимость), факт (количество, цена, стоимость), отклонение (количество, цена, стоимость).

| Колонка | Формула |
| --- | --- |
| План | Ввод во вводе плана |
| Цена | Плановая цена закупки с НДС и без НДС |
| Стоимость | Плановая цена × плановое количество |
| Факт | Сумма журнала прихода за месяц |
| Цена | Стоимость факта / количество. Прихода не было — пусто |
| Стоимость | Сумма строк журнала, с НДС и без НДС |
| Откл. | Факт − план (количество) |
| Откл. | Факт − план (цена). Нет факта — пусто |
| Откл. | Факт − план (стоимость) |

## Расход в производстве

| Колонка | Формула |
| --- | --- |
| План | Ввод в колонке «План» отчёта (временно; позже — из плана выпуска) |
| Факт | Ввод в колонке «Факт» отчёта |
| Откл. | Факт − план |
| Цена | Цена прихода, если приход был, иначе плановая цена. `DSM Meat!R8` |
| Стоимость | Количество × эта цена |

## Остаток на конец

| Колонка | Формула |
| --- | --- |
| План | Начало + факт прихода − факт расхода |
| Факт | Инвентаризация. Ввод — в инвентаризации сырья |
| Откл. | Факт − план. Минус — недостача этого склада |
| Мин. / Макс. | Ввод плана |
| Откл. от норм. | Ниже минимума или выше максимума относительно факта конца |
| Стоимость | Факт конца × цена расхода |

«Всего» по количеству есть только если у всех строк одна единица. Деньги складываются всегда. Склад 1 и склад 2 не складываются.
