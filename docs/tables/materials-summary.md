# Отчет общий сырья

`/materials`. Четыре группы. В каждой две таблицы: склад 1 и склад 2. Общего итога двух складов нет.

Считает `src/domain/materials.ts`.

## Остаток на начало

| Колонка | Формула |
| --- | --- |
| Остаток | Инвентаризация конца прошлого месяца этого склада. Январь 2000 или нет записи — 0 |

## Приход от поставщика

Девять колонок: план (количество, цена, стоимость), факт (количество, цена, стоимость), отклонение (количество, цена, стоимость).

| Колонка | Формула |
| --- | --- |
| План · Кол-во | Ввод во вводе плана |
| План · Цена | Плановая цена закупки с НДС и без НДС |
| План · Стоимость | Плановая цена × плановое количество |
| Факт · Кол-во | Сумма журнала прихода за месяц |
| Факт · Цена | Стоимость факта / количество. Прихода не было — пусто |
| Факт · Стоимость | Сумма строк журнала, с НДС и без НДС |
| Отклонение · Кол-во | Факт − план (количество) |
| Отклонение · Цена | Факт − план (цена). Нет факта — пусто |
| Отклонение · Стоимость | Факт − план (стоимость) |

## Расход в производстве

Девять колонок: план (количество, цена, стоимость), факт (количество, цена, стоимость), отклонение (количество, цена, стоимость).

| Колонка | Формула |
| --- | --- |
| План · Кол-во | Ввод в колонке «Кол-во» отчёта (временно; позже — из плана выпуска) |
| План · Цена | Плановая цена закупки |
| План · Стоимость | Плановая цена × плановое количество |
| Факт · Кол-во | Ввод в колонке «Кол-во» отчёта |
| Факт · Цена | Цена прихода, если приход был, иначе плановая цена. `DSM Meat!R8` |
| Факт · Стоимость | Эта цена × фактическое количество |
| Отклонение · Кол-во | Факт − план (количество) |
| Отклонение · Цена | Факт − план (цена) |
| Отклонение · Стоимость | Факт − план (стоимость) |

## Остаток на конец

| Колонка | Формула |
| --- | --- |
| План | Начало + план прихода − план расхода |
| Текущий · Факт | Начало + факт прихода − факт расхода |
| Текущий · Откл. | Текущий факт − план |
| Текущий · Стоим. откл. | Отклонение × цена расхода |
| Инвентаризация · Факт | Инвентаризация. Ввод — в инвентаризации сырья |
| Инвентаризация · Откл. | Факт инвентаризации − план |
| Инвентаризация · Стоим. откл. | Отклонение × цена расхода |
| Мин. / Макс. | Ввод плана |
| Откл. | Ниже минимума или выше максимума относительно факта инвентаризации |
| Стоимость | Факт инвентаризации × цена расхода |

«Всего» по количеству есть только если у всех строк одна единица. Деньги складываются всегда. Склад 1 и склад 2 не складываются.
