# Ввод плана производства

`/production/plan`. Месяц. Справочник здесь не правят. Цен, выручки и Т-протока нет. Над столбцами группа «Плановые показатели», как во [вводе плана продаж](sales-plan.md).

Считает `src/domain/production-plan.ts`. Рекомендуемый объём — `src/domain/movement-plan.ts`.

## Колонки строки товара

| Колонка | Откуда |
| --- | --- |
| Себест | Ввод [себестоимости 1 шт](../flow.md#unit-cost) товара, с НДС или без НДС. Меняет товар, не строку плана |
| Рекомендуемый объём | Та же цифра, что во [вводе плана движения](movement-plan.md). Здесь только смотрят |
| Объём | Ввод, шт выпуска. Не равен объёму продаж |
| Себест объёма | Себестоимость штуки × объём. В документ не пишется. См. [себестоимость объёма](../flow.md#volume-cost) |

Категория и «Всего»: сумма объёмов, сумма себестоимостей объёма, сумма рекомендаций. Себестоимость штуки итога = себестоимость объёма / объём.

## Что пишется

Строка плана — только штуки выпуска. Себестоимость — на товаре.

Этот объём и эта себестоимость — план в [отчёте общем производства](production-summary.md).
