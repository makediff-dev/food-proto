# Ввод плана (производство)

`/production/plan`. Месяц. Справочник здесь не правят. Себестоимость единицы правят во [вводе плана продаж](sales-plan.md). Над столбцами группа «Плановые показатели».

Считает `src/domain/production-plan.ts`. Рекомендуемый объём — `src/domain/movement-plan.ts`. Цена — расчётная цена плана продаж месяца.

## Колонки строки товара

| Колонка | Откуда |
| --- | --- |
| Объём | Ввод, шт выпуска. Не равен объёму продаж |
| Рекомендуемый объём | Та же цифра, что во [вводе плана движения](movement-plan.md). Здесь только смотрят |
| Цена | Расчётная цена плана продаж месяца. Только смотрят |
| Стоимость | Цена × объём. В документ не пишется |

Категория и «Всего»: сумма объёмов, сумма стоимостей, сумма рекомендаций. Цена итога = стоимость / объём.

## Что пишется

Строка плана — только штуки выпуска.

Этот объём и эта стоимость — план в [отчёте общем производства](production-summary.md).
